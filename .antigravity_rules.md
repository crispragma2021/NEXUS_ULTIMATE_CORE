# PROTOCOLO DE REUTILIZACIÓN ESTRICTA (NEXUS CORE)

Antes de crear un nuevo archivo, script o estructura, DEBES cumplir obligatoriamente estos 3 pasos:

1. **Paso 1 - Auditoría de Inventario:**
   - Consulta `NEXUS_CATALOG.md` para verificar qué módulos, utilidades y servicios ya existen.
   - Si una funcionalidad ya está implementada (ej. captura con `vision.rs`, túneles, proxy, base de datos), ESTÁ PROHIBIDO reescribirla.

2. **Paso 2 - Vinculación por Referencia:**
   - Si la funcionalidad existe, impórtala o llámala mediante interfaz (CLI, API local o módulo de Rust/JS).
   - Solo escribe código para los "puentes" o "adaptadores" que conectan lo existente con lo nuevo.

3. **Paso 3 - Declaración Explícita:**
   - Al presentar tu plan, debes listar:
     - 🟢 Componentes existentes que vas a REUTILIZAR.
     - 🟡 Adaptadores/conexiones que vas a CREAR.
     - 🔴 Únicamente lo estrictamente nuevo que no existe en el catálogo.
