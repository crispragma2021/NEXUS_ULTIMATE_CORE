# 🌌 PLANO MAESTRO OMEGA: NEXUS CHAT SOBERANO

Este documento es el plano genético para la transmutación del chat de Antigravity hacia el ecosistema nativo NEXUS.

## 🎨 ADN VISUAL (Inspiración Antigravity/Cursor)
- **Fondo:** `#1e1e2e` (Deep Blue Night)
- **Acento Primario:** `#00ff88` (Neon Sovereign Green)
- **Acento Secundario:** `#88ddff` (User Cyan)
- **Estilo:** Glassmorphism, bordes redondeados (8px), desenfoque de fondo (10px).

## 🚀 MOTOR DE VELOCIDAD (Inspiración Zed/Rust)
- **Frontend:** Tauri v2 + Vite + React (o Vanilla JS para máxima pureza).
- **Backend UI:** Rust (Tauri Commands/IPC).
- **Orquestador Central:** Axum sobre Tokio (Server local en puerto 43211).
- **Base de Datos:** SQLite + LanceDB (Vectores).
- **Paralelismo:** Optimizado para Intel i7-12700F (20 hilos nativos vía Tokio).

## 🧠 FUNCIONALIDADES CLAVE
1. **Flow Contextual Atómico:** Mapeo de archivos del workspace en tiempo real con sincronía bidireccional entre Axum y el Editor.
2. **Ghost Mode:** Capacidad de la ventana de chat de volverse transparente y flotante.
3. **Sovereign Gateway:** Selección de modelos con rotación automática de keys (Zenith Pool).
4. **Offline Resilience:** Caché local de modelos y pesos para operación en aislamiento total.
5. **Terminal Bridge:** Ejecución directa de ráfagas de comandos desde el chat.
